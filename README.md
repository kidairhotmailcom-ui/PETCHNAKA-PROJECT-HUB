# AUTO SHOP PRO — Promotional Website

เว็บไซต์ประชาสัมพันธ์ภาษาไทยแบบ Static พร้อมใช้งานบน GitHub Pages

## ไฟล์
- `index.html` — หน้าเว็บทั้งหมด (CSS และ JavaScript อยู่ในไฟล์เดียว)

## อัปโหลดขึ้น GitHub
1. สร้าง Repository ใหม่ เช่น `auto-shop-pro-promo` หรือใช้ Repository เว็บไซต์กลางที่เตรียมไว้
2. เลือก `Add file` → `Upload files`
3. อัปโหลด `index.html` และ `README.md` (หรืออัปโหลดเนื้อหาทั้งโฟลเดอร์)
4. กด `Commit changes`
5. ไปที่ `Settings` → `Pages`
6. เลือก `Deploy from a branch` → Branch `main` → Folder `/(root)` → `Save`
7. รอ GitHub Pages เผยแพร่ แล้วเปิด URL ที่ GitHub แสดงให้

## ก่อนเผยแพร่จริง
- แก้ปุ่มอีเมลใน `index.html` โดยค้นหา `ใส่อีเมลบริษัทที่นี่` แล้วแทนด้วยอีเมลจริง
- ตรวจสอบคำอธิบายฟังก์ชันให้ตรงกับความสามารถที่เปิดใช้งานจริงของ AUTO SHOP PRO
- ภาพหน้าจอแดชบอร์ดในหน้านี้เป็น Mockup ที่สร้างด้วย HTML/CSS ไม่ใช่ภาพระบบจริง
- ไม่ได้เชื่อมฐานข้อมูล ไม่ได้มีระบบสั่งซื้อ/ชำระเงิน และไม่ได้มีหลังบ้านในชุดประชาสัมพันธ์นี้
- ราคาและโปรโมชั่นไม่ได้ระบุตายตัว เพื่อป้องกันการเผยแพร่ราคาเก่าหรือเงื่อนไขที่ยังไม่ยืนยัน
