# PETCHNAKA PROJECT HUB

เว็บไซต์สาธารณะสำหรับแสดงภาพรวมโครงการของบริษัท เพชรนาคา ซิสเต็มเวิร์ค จำกัด

## หน้าเว็บไซต์
- `index.html` — หน้า Hub รวมโครงการและสถานะภาพรวม
- หน้า Hub ไม่ทำหน้าติดต่อซ้ำ ปุ่มสมัคร/ติดต่อเชื่อมไปยังหน้า AUTO SHOP PRO
- ไม่เพิ่มช่องทาง LINE หรือ Facebook

## โครงการที่แสดง
- AUTO SHOP PRO — ลิงก์ไปยังเว็บไซต์ที่เปิดให้เข้าชม
- SAFE-ELEC — แสดงสถานะระหว่างพัฒนา
- AUTO IoT PRO — แสดงสถานะระหว่างพัฒนา
- PETCHNIKKA JARVIS CORE — แสดงเป็นระบบภายใน

สถานะบนหน้า Hub เป็นข้อมูลภาพรวม ไม่ใช่การรับรองว่าทุกฟังก์ชันของโครงการพร้อมใช้งาน

## การทดสอบ
GitHub Actions workflow `.github/workflows/hub-quality-check.yml` ตรวจสอบ:
- โครงสร้าง HTML เบื้องต้นและการมี title / h1
- id ต้องไม่ซ้ำ และลิงก์ภายในต้องชี้ไปยัง element ที่มีอยู่
- ลิงก์สมัคร/ติดต่อมีเพียงลิงก์ที่กำหนดไป AUTO SHOP PRO
- ไม่มี LINE, Facebook, mailto หรือ tel บนหน้า Hub
- ตรวจว่าเว็บไซต์ AUTO SHOP PRO ปลายทางตอบกลับและมีเนื้อหาที่คาดหมาย
